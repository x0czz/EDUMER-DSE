    talento  = if_else(perfil %in% c("B", "C"), 1L, 0L),
    # Variable binaria complementaria: 3 o más décimas permiten aprobar (3,7 -> 4,0)

Centrado de las variables de nivel 1 y medias de clúster

Las variables de nivel 1 son los atributos del perfil (esfuerzo y talento). El clúster es el estudiante (id_estudiante). Se calculan:

  • Media del clúster (_cm): proporción de perfiles con el atributo dentro de cada estudiante.
  • Centrado a la media global, GMC (_gmc): el atributo menos su media en toda la muestra.
  • Centrado a la media del clúster, CWC (_cwc): el atributo menos la media de su estudiante. Se crea solo para comprobar que coincide con el GMC.
set_exp <- set_exp %>%
  group_by(id_estudiante) %>%
  mutate(
    esfuerzo_cm = mean(esfuerzo, na.rm = TRUE),   # media del clúster (estudiante)
    talento_cm  = mean(talento,  na.rm = TRUE)
  ) %>%
  ungroup() %>%
  mutate(
    # Centrado a la media global
    esfuerzo_gmc = esfuerzo - mean(esfuerzo, na.rm = TRUE),
    talento_gmc  = talento  - mean(talento,  na.rm = TRUE),

    # Centrado a la media del clúster (para verificar)
    esfuerzo_cwc = esfuerzo - esfuerzo_cm,
    talento_cwc  = talento  - talento_cm
  )

Como cada estudiante evalúa los cuatro perfiles, la media del clúster es constante (0,5) y el GMC es idéntico al CWC. Se verifica a continuación (eval: false; cámbialo a true para verlo en el documento).

# Media de clúster: debe valer 0.5 para todos los estudiantes

Modelos con los atributos centrados

Con el GMC, el intercepto es la asignación esperada en el punto medio entre condiciones (2,5 décimas, que es el promedio fijo por la suma de 10), y los coeficientes de esfuerzo_gmc y talento_gmc siguen siendo la diferencia entre condiciones. Al centrar ambos atributos, los coeficientes de cada uno son efectos principales (promediados sobre el otro atributo) y no efectos condicionales al grupo de referencia.
